# E-commerce Product Detail Page (PDP)

This project is a responsive Product Detail Page built with React, TypeScript, and Vite. It features dynamic variant selection, real-time stock/price updates, and a simulated add-to-cart flow.

## 🚀 How to Run

1. **Clone the repository** and navigate to the frontend folder:
   ```bash
   cd frontend
   npm install
   npm run dev
